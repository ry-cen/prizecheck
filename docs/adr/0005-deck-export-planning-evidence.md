# Use Limitless comparison for Deck export planning evidence

**Status:** accepted — owner instruction, 2026-10-08.

The Card prices and Deck exports Wayfinder effort produces an agreed plan; `/to-spec` and `/to-ticket` handle the later handoff. During [Verify live price and export fixtures](https://github.com/ry-cen/tcg-tracker/issues/40), native app access reported the Mac locked. Asked to open Pokémon TCG Live for an import check, the owner instead instructed: “compare against a similar deck on limitless”. The owner separately authorized replacing the clipboard with the public reference deck list.

The active planning evidence criteria are bounded TCGdex fixture coverage, comparison of two similar public Limitless lists against its inspected formatter, an authorized Copy action with the observed result recorded, and TCGplayer Mass Entry prefill observation. A clipboard byte capture is evidence only if available; an empty tool result must not be represented as a captured payload. The investigation may close with these observations and explicit limits. It does not close as a successful Pokémon TCG Live compatibility check.

Actual Live importer acceptance, promo/ALT/subset mappings, malformed/incomplete input behavior, exact physical marketplace matching, and cart resolution remain separate implementation/launch handoff checks. A Limitless comparison or a prefilled product-ID list cannot satisfy them. Product scope, physical Card Edition identity, privacy rules and the accepted export fallback contract remain in force.

This replaces the current investigation's attempt to obtain in-game evidence with the owner's selected reference comparison. Historical criteria remain in its ticket. The evidence and remaining checks are recorded in the [resolution](../planning/tcg-collection-tracker/wayfinder/resolutions/21-verify-price-and-export-fixtures.md).
