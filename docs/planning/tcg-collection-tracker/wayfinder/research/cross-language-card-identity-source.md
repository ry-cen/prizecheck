# Cross-language Card Identity sources for Pokémon TCG

Research checked 2026-09-28 (America/Los_Angeles). This investigates **name equivalence for deck copy limits**, not whether two printings have the same attacks, art, or set position. Sources below are the source owners' rules, documentation, data, and terms. Commercial and community catalogs are identified as unofficial.

## Finding

No inspected official Pokémon resource exposes a documented, reusable English↔Japanese **card-name identity ID** covering Pokémon, Trainers, and Energy. The [official English card database](https://www.pokemon.com/us/pokemon-tcg/pokemon-cards/) and [official Japanese card search](https://www.pokemon-card.com/card-search/) show localized card records, but neither documents a cross-language identity relation or developer API for it. This is a finding about the inspected public interfaces, not proof that Pokémon has no internal mapping. The [Pokémon Company International website terms](https://www.pokemon.com/uk/legal/terms-of-use) restrict downloading quantities of site content into a database; direct bulk ingestion from either official site needs separate rights review.

The official Japanese [rules page](https://www.pokemon-card.com/howtoplay/) says cards of the same name are limited to four. Its [manual](https://www.pokemon-card.com/assets/document/manual.pdf) expressly treats cards with different attacks or illustrations as the same name, and distinguishes cards whose printed names differ. Its [advanced rules](https://www.pokemon-card.com/assets/document/advanced_manual.pdf) distinguish Basic Energy, which is exempt, from Special Energy, to which the four-copy rule applies. [Pokémon's English explanation](https://www.pokemon.com/us/features/big-changes-in-pokemon-tcg-sun-moon) confirms that name modifiers such as “Alolan” matter. Consequently, Card Identity is a **rules-relevant name group**, not a species, matching-art, matching-effect, or identical-printing group. Different Pikachu cards with the same printed name count together; Pikachu ex is a distinct name. The checker still needs card-specific limit exceptions in a later legality phase.

The [older Pokémon TCG API data repository](https://github.com/PokemonTCG/pokemon-tcg-data) now calls itself legacy and says its API will be retired in 2027; it is not a sound new dependency for this mapping.

## How an external translation can help without changing the model

The application can create one Card Identity per reviewed rules-relevant name and attach many Card Printings to it. A translation record supplies a **candidate pair** such as `(en: Pikachu ex, ja: ピカチュウex)`. After review, every Printing bearing the same exact normalized name in either language may attach to that Card Identity, even if the Printings have different attacks or art. A `jp_twin_id` or equivalent printing pair can provide evidence for a name pair, but the twin relation itself is too narrow to define the copy-limit group. This follows the official name rule and the commercial APIs' documented structures. ([Official Japanese rules](https://www.pokemon-card.com/assets/document/manual.pdf); [pokemontcgapi card schema](https://pokemontcgapi.com/docs/objects/card))

Import logic must use **explicit, present** translation values; `?lang=` fallback output is unsafe evidence. Preserve source, source card ID, observed localized names, observed time/version, review status, and the reviewing decision. Normalize Unicode and insignificant whitespace for comparison while retaining punctuation, suffix case, possessives, and the printed display name. If one normalized Japanese name proposes multiple English names, or vice versa, queue a conflict rather than automatically merging identities. A newer source translation must not silently relink an existing Printing or its Holdings. These are recommended application safeguards inferred from the source gaps, not guarantees made by any provider. ([pokemontcgapi get-card contract](https://pokemontcgapi.com/docs/api/cards/get); [Scrydex translation behavior](https://scrydex.com/docs/pokemon/api-reference))

Unreleased Japanese cards may have no official English card name. A provider's English gloss for such a card can help search, but should not be treated as a final localized rules name until reviewed. Historical name changes, punctuation, `ex` versus `EX`, owner names, regional forms, Trainers whose displayed parenthetical identifies an artwork, and Basic-versus-Special Energy classification need focused fixtures. Pokédex number, set number, artwork, attack text, or machine translation alone cannot resolve those cases. ([Official English name-modifier example](https://www.pokemon.com/us/features/big-changes-in-pokemon-tcg-sun-moon); [TCGdex source schema](https://github.com/tcgdex/cards-database/blob/master/interfaces.d.ts); [PokéAPI species scope](https://pokeapi.co/docs/v2#pokemon-species))

## Recommendation for the MVP decision

1. Keep **TCGdex as the Printing catalog** and an **application-owned Card Identity table** as the copy-limit grouping authority. This avoids changing inventory source identity merely because a translation vendor changes. Use exact normalized names to group Printings within each language. For cross-language grouping, admit only reviewed EN↔JA name pairs or reviewed Printing-to-Identity links.
2. Seed a small reviewed mapping from official English/Japanese card examples and publicly available community candidates, keeping provenance on every link. The open community datasets are aids for reviewing candidates, not an automatic rules engine or a complete launch dataset. Do not infer cross-language equality from species or printing fingerprints.
3. Before buying any provider, run a finite evaluation of pokemontcgapi.com's `translations` and `jp_twin_id` against a fixture spanning Pokémon with the same name but different attacks, suffixes (`ex`/`EX`/`GX`), regional/owner prefixes, Trainer reprints, Basic and Special Energy, older eras, and Japanese cards without Western releases. Measure **joint EN+JA translation coverage**, conflicts, and source-to-TCGdex record joinability; the published locale totals do not answer those questions. Scrydex is a second paid comparison if the first fails.
4. If no reviewed link exists, let the card remain in inventory and report the affected deck copy-limit result as **unresolved**. Never report that a mixed-language deck passes the four-copy check solely because the mapping is absent. Basic Energy and card-specific exceptions require separate verified classifications.

**Decision still needed:** whether the product accepts incomplete mixed-language copy-limit evaluation at launch, funds an ongoing paid translation source plus review, or narrows the supported deck-check language scope. None of the inspected sources makes a complete, authoritative, low-cost EN↔JA Card Identity feed available out of the box.
