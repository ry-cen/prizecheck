**Status:** open

**Assignee:** unassigned

## Question

What broader visual system should follow the approved collector-workspace interaction while preserving accessibility and mobile capability?

## Established direction

The core collector-workspace rules are accepted in [collector workspace selection and presentation](../resolutions/29-decide-collector-workspace-selection-and-presentation.md). This ticket extends that direction; it does not reopen it. No large-artwork mandate, dedicated deck-building UI, or broad light-theme direction is accepted.

## Scope and acceptance criteria

- Define reusable visual roles and responsive treatment for Locations, Collection, Decks, details, loading/error/conflict/success/Undo states, focus, contrast, target size, screen-reader labeling, and reduced motion.
- Define desktop/mobile outcome parity and explicit presentation differences.
- Preserve the linked accepted direction and identify any new owner decisions rather than claiming a complete redesign.
