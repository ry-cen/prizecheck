## Question

Which credible, maintainable data source or combination of sources can map rules-relevant Pokémon TCG card names across English and Japanese so that all cards with the same name count under one Card Identity, including Pokémon with name suffixes, Trainers, and Energy? Determine available identifiers, coverage, provenance, licensing or usage constraints, update behavior, integration cost, and the unresolved cases that still require reviewed Catalog Overrides. Prefer official first-party APIs, databases, rules, and source repositories; distinguish authoritative evidence from community-maintained fallback data.
